## ز) النواقص المعلَنة (لا تُخفى)

1. **الواجهة**: اكتملت وبُنيت إنتاجيًا، ودُخِّنت عبر E2E (توجيه الدخول + حقول + ترويسات
   + 6 مقاسات). **التفاعلات العميقة لكل شاشة** (إنشاء/تعديل من الواجهة نفسها) لم تُجتَر
   آليًا — السلاسل الحرجة مُغطّاة عبر API في E2E.
2. **TOTP**: مُنفَّذ ومُغطّى باختبار وحدة؛ **تدفق 2FA الحيّ عبر الواجهة** لم يُختبر.
3. **الهجرة Prisma**: طُبِّق المخطط عبر `db push`؛ لم تُولَّد ملفات `migrations/` SQL.
4. **backups/worker/seed-load/docker**: مكتوبة ولم تُشغَّل في هذه البيئة.
5. **التزامن الثقيل** (EXCLUDE وتداخل الدفعات تحت ضغط متوازٍ متعدد العمال): لم يُقس.
