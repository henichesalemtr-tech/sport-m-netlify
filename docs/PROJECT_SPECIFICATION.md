## 1) النطاق (Scope)

نظام إدارة رياضية احترافي ذاتي الاستضافة (Self-Hosted) للنوادي والأكاديميات والجمعيات
الرياضية، عربي RTL بالكامل، يغطي:

- **الهوية والوصول:** مستخدمون بأدوار نظامية (SUPER_ADMIN, ADMIN, RECEPTION, COACH,
  ACCOUNTANT, VIEWER) + صلاحيات دقيقة قابلة للتخصيص، جلسات قاعدة بيانات، Argon2id،
  قفل ضد التخمين، TOTP اختياري.
- **الرياضيون والأولياء:** ملفات رياضيين (مع حقول حساسة طبية محمية بصلاحيات)،
  أولياء بعلاقات عدة-إلى-عدة (أساسي/دافع/طوارئ)، كشف التكرار، أرقام تسجيل تسلسلية
  بصيغة قابلة للضبط، حذف ناعم واستعادة.
- **البنية الرياضية:** أنشطة، فئات عمرية (بحدود عمرية ومرجع موسم)، قاعات/ملاعب،
  مدربون، مجموعات بسعة قصوى، عضويات بقفل صف ضد تجاوز السعة.
- **الجدولة والحضور:** حصص تدريب/مباريات/أنشطة بتوليد تكراري، كشف تعارض
  (مدرب/قاعة/مجموعة) في طبقة التطبيق (`src/modules/sessions/recurrence.ts` + أقفال
  `FOR UPDATE` — لا يوجد قيد EXCLUDE في MySQL)، حضور (يدوي/جماعي/مسح رمز)
  مع منع التكرار وحساب التأخر واستهلاك حصص الاشتراكات.
- **الماليات:** أنواع اشتراك (زمنية/حصص/مخصصة)، اشتراكات بحالات وانتقالات مضبوطة
  وتجديد بلا مسح السجل القديم، دفعات BigInt بأصغر وحدة مع Idempotency،
  وصولات تسلسلية بلا فجوات لكل سنة مالية (مع إعادة طبع marked)، إلغاء/استرداد،
  مصاريف، دفتر خزينة Append-Only مع إقفال يومي وتسوية.
- **المساندة:** تقييمات رياضية بقوالب، وثائق رياضي بأنواع وتواريخ انتهاء،
  إشعارات داخل التطبيق (قنوات خارجية معطلة افتراضيًا)، استيراد CSV/Excel بمعاينة
  وتخطيط أعمدة وتقارير أخطاء، تقارير (14 نوعًا) وتصدير Excel/CSV، لوحة تحكم
  بمؤشرات ورسوم، سجل تدقيق Append-Only، نسخ احتياطي `mysqldump` بسياسة GFS واستعادة
  آمنة، مهام مجدولة (انتهاء اشتراكات، إشعارات، وثائق قاربت الانتهاء، نسخ، تسوية).

**خارج النطاق:** بوابات دفع إلكتروني، تطبيقات موبايل أصلية، محاسبة ضريبية كاملة،
نظام بطولات متكامل، تكامل واتساب/SMS فعلي (البنية موجودة والقنوات معطلة افتراضيًا).

## 3) دورة العمل الكاملة (Workflow Cycle)

1. **الإعداد الأولي:** تهيئة القاعدة (`npx prisma db push`) + القيود الخام
   (`mysql -u root sports_management < prisma/raw-constraints.sql`) → `npm run seed` (صلاحيات، أدوار،
   طرق دفع، فئات مصاريف، أنواع وثائق، فئات عمرية، إعدادات) → إنشاء أول Super Admin
   (عبر `SEED_ADMIN_*` حاليًا؛ Setup Wizard في الواجهة غير منفذ بعد — انظر PROGRESS).
2. **البنية:** إنشاء الأنشطة → الفئات العمرية → القاعات → المدربون → المجموعات
   (سعة + أيام/أوقات التدريب).
3. **التسجيل:** إنشاء الأولياء → الرياضيون (ربط ولي أساسي/دافع، رقم تسجيل تسلسلي
   تلقائي، كشف تكرار بالاسم/تاريخ الميلاد) → رفع الوثائق (شهادة طبية…) →
   إضافة للمجموعة (فرض السعة بقفل صف؛ التجاوز يتطلب صلاحية + سببًا + Audit).
4. **الاشتراك:** إنشاء نوع اشتراك (سعر BigInt) → اشتراك للرياضي (خصم بسبب إلزامي
   وصلاحيات apply_discount) → منع تداخل اشتراكين نشطين لنفس الرياضي والنشاط.
5. **الدفع:** تسجيل دفعة (Idempotency-Key، منع الدفع الزائد افتراضيًا، إعادة اشتقاق
   paidAmount من الدفعات غير الملغاة) → توليد وصل تسلسلي بلا فجوات → قيد خزينة
   INCOME تلقائي → Audit — الكل في معاملة واحدة.
6. **الجدولة:** توليد حصص متكررة من جدول المجموعة → كشف تعارض المدرب/القاعة/المجموعة
   في طبقة التطبيق (`FOR UPDATE` على صفوف الموارد) → إلغاء/إعادة جدولة بسبب.
7. **الحضور:** ورقة حضور جماعية أو مسح رمز الرياضي (HMAC + منع تكرار خلال
   scan.dedupSeconds) → حساب التأخر تلقائيًا حسب attendance.lateMinutes →
   استهلاك حصة من اشتراكات الحصص → تنبيه غياب متتابع
   (attendance.consecutiveAbsenceAlert).
8. **المصاريف والخزينة:** رصيد افتتاحي → دفعات INCOME/مصاريف EXPENSE → تسويات
   بسبب → إقفال يومي (متوقع مقابل معدود + فرق + سبب).
9. **التجديد والانتهاء:** مهمة يومية تعلّم المنتهي EXPIRED → تنبيهات قبل الانتهاء
   (subscription.expiringDays) → تجديد (القديم RENEWING ولا يُمسح، الجديد يبدأ
   يومًا بعد النهاية أو اليوم إذا منتهي حسب الإعداد).
10. **التقارير والتدقيق:** تقارير مالية/حضور/ديون + تصدير Excel/CSV معقّم ضد
    حقن الصيغ → سجل تدقيق غير قابل للتعديل → نسخ احتياطي يومي/أسبوعي/شهري.
